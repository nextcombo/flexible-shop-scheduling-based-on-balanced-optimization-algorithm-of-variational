# Flexible Shop Scheduling Based on Balanced Optimization Algorithm of Variational Neighborhood Search and Mycobacterium Cocci-like Algorithm (Matlab Code Implementation)

💥1 Overview
The flexible job shop scheduling problem (FJSP) is a research topic that studies the allocation of production resources and the sequencing of workpiece operations. It features characteristics such as unpredictable processing equipment and flexible process routes. In actual workshop production environments, many workpiece processes have a precedence relationship, which may include situations where operations share a common predecessor or multiple predecessors.
This paper focuses on flexible workshop scheduling using two novel algorithms: the variable neighborhood search balanced optimization algorithm and the sticky algorithm. The implementation is carried out using Matlab code.
